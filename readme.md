# API Lab

## Descripción

Este proyecto se realizó para la materia de Arquitectura de aplicaciones web, con el objetivo de implementar diferentes patrones de diseño en una API.

## Patrones de diseño implementados

- REST
- gRPC
- GraphQL

*Nota: Cada uno de estos patrones se implementó en su propia carpeta, con su respectivo README.md para facilitar la comprensión y ejecución de cada uno.*
*Nota: En la carpeta Test se encuentra la colección de peticiones para probar las APIs implementadas. Esta colección se puede importar en Bruno. https://www.usebruno.com/*
*La especificación gráfica del funcionamiento se encuentra en el archivo: Diagrama.drawio. Este documento se puede abrir con el software Draw.io. https://www.drawio.com/*
